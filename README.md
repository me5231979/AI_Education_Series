# AI Education Series

Vanderbilt staff AI courses and the AI Readiness survey, as static pages.

| Path | What it is |
| --- | --- |
| `/` | Working Smarter, the self-paced course |
| `/classroom/` | Working Smarter, classroom edition |
| `/answers/`, `/ideas/`, `/drafts/`, `/minutes/`, `/slides/`, `/decisions/` | The six "faster" courses (self-paced) |
| `/*-class/` and `/*-class/facilitator/` | Classroom and facilitator editions |
| `/managers/` | Manager job aid (`job-aid.html` prints) |
| `/survey/` | AI Readiness survey |

Moved here from the estesstite repo, which now redirects its old `/learn/`
and `/survey/` addresses to this site so printed QR codes keep working.

Hosting: GitHub Pages, deployed from the `main` branch root (no build step).
